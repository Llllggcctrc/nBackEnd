Sistema de Manutenção so senai - tpm Industrial 

Objetivo: para consolidar os conceitos de moldel controller e blade 

## Cenario do projeto 

na industria paradas ão planejadas de maquinas criticas custam de milhares de reais por minutos ou horas
A aplicação deve gerencia
1 **equipamentos industriais**: tag de patrimonio setor, criatividade (alta ,media, baixa) e status operacionais 
2. **ordens do serviços**: tipo  de manutenção(previtivas, correitivas predititas ), prioridade, tecnico responsavel, data limite de status (ABERTA EM_ANDMENTO, CONCLUIDA)
3. **painel de inceradodres**: calcular em tempo reak equpamentos em operações ordens de emergencias e taca de conformidade de manutenção
